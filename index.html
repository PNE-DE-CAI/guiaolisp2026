👤 Quem são os fiscais?

Fiscais de prova são pessoas responsáveis por acompanhar, supervisionar e garantir o bom andamento da aplicação da OLISP. Aconselhamos que sejam membros do corpo docente ou do trio gestor.

💡 Dica: Desaconselhamos que sejam professores de Língua Portuguesa.

🔧 Estudante sem avaliação disponível na Sala do Futuro

  1. Verificar se o login está correto — erro recorrente de digitação. Confirmar se o estudante está no login correto.
  2. Verificar se a data e hora do computador estão atualizadas. A prova não abre se estiverem diferentes do real. Sugestão: trocar o computador.
  3. Se o problema persistir, esvaziar o cache do navegador (atalho: Ctrl + Shift + Delete) ou utilizar a guia anônima.
  4. Lembrar: a prova só estará aberta no turno de aplicação.

⚡ Escola sem conexão à internet/energia

🔌 Protocolo de contingência:
1. Verificar disponibilidade de tablets com chip na escola, na URE ou escola vizinha.
2. Em último caso, celulares podem ser usados emergencialmente.
3. Verificar possibilidade de deslocar estudantes para escola vizinha.
🚫 ATENÇÃO: O uso de celular é expressamente proibido, salvo a exceção acima (falta de internet/energia).

🔍 Protocolo para identificação de cola

Os estudantes que burlaram a aplicação devem ser informados no momento em que o fiscal percebeu a tentativa de cola e devem ser desclassificados caso o ato seja confirmado.

Para desclassificar: marcar ausência no Diário de Classe e informar o ponto focal de Olimpíadas da Diretoria de Ensino.
  • Conhecer soluções para login e cache
  • Verificar tablets com chip disponíveis
  • Identificar escola vizinha para contingência
  • Conhecer protocolo de desclassificação por cola

📝 Processo de aplicação da prova

O fluxo completo de aplicação segue estas etapas:

  1. Organizar espaço adequado na escola para aplicação de prova.
  2. Conduzir alunos para a aplicação da prova.
  3. Gerar o token (preferencialmente pelo trio gestor).
  4. Registrar a presença dos estudantes na lista de chamada na SED.
  5. Desclassificar estudantes com ocorrências na SED.

📊 Enturmação e Frequência

Caminho na SED: Início → Diário de Classe → Olimpíadas → Enturmação e Frequência.
  • Selecione os dados da sua URE e a turma do ensalamento correta.
  • Na tabela de estudantes haverá, no dia da prova, um botão para marcar AUSÊNCIA.
  • Selecione para marcar os estudantes que não fizeram a prova na escola.
🚫 Desclassificação: Para desclassificar estudantes que burlaram o processo de prova, use também a marcação de AUSÊNCIA no Diário de Classe.
  • Organizar espaço de aplicação
  • Saber navegar no Diário de Classe (SED)
  • Registrar presenças e ausências corretamente

🔐 O que é o Token?

Na Fase 2 da OLISP, o token poderá ser gerado em lote pelas unidades escolares. A escola deverá gerar um mesmo token de aplicação para todas as turmas.

Token de Atividades
••••••••

📌 Regras importantes

  • Indicamos que algum membro do trio gestor seja responsável por gerar o token.
  • O token tem a duração de 30 minutos. Se um estudante chegar atrasado e o token já tiver expirado, um novo deverá ser gerado.
  • Siga as instruções para que o token esteja visível para todos e evite que várias pessoas gerem o token.

🔄 Tipos de Token

TipoDescrição
Token por turmaUm token por turma do ensalamento. Ex: 3 turmas N1 usam Token #1; 4 turmas N2 usam Token #2.
Token em loteUm token para todas as turmas da escola. Exige que todas as turmas sejam associadas a um único token.

📍 Como gerar o Token

Na Sala do Futuro, acesse a geração de token pelo ícone no menu principal e também pelo menu lateral. Na tela do Token de Atividades, escolha a turma onde a prova será aplicada.

O token também pode ser gerado pelo Gerenciador.

📎 Material de apoio: Consulte o tutorial "Como gerar um Token em lote" e a "LIVE — Orientações de Aplicação da Prova de Recuperação" para instruções detalhadas.
  • Designar responsável para gerar o token (trio gestor)
  • Escolher tipo de token (por turma ou em lote)
  • Garantir que o token esteja visível para todos
  • Preparar geração de novo token para atrasados (validade: 30 min)

❓ "Se um estudante veio transferido de outra escola para realizar a prova na minha turma, o que devo fazer?"

Se na sua escola há algum estudante novato e apto para realizar a prova, mas a classificação e enturmação já foi feita na escola de origem:

  1. Comunicar com a escola antiga para que o trio gestor, Proati ou algum professor informe, no momento da prova, qual é o token de acesso.
  2. Caso contrário, o estudante não conseguirá abrir a prova na Sala do Futuro.
⏰ Nota Importante: O estudante só poderá realizar a prova na data e turno programado. Portanto, esse contato deve ser feito da forma mais rápida possível.
  • Identificar alunos transferidos antes da prova
  • Contatar escola de origem para obter token
  • Garantir contato rápido e eficiente
